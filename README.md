# Vier Gewinnt (Connect Four) 🎮

Ein visuell ansprechendes Vier-Gewinnt-Spiel, implementiert mit p5.js und automatisch über GitHub Pages veröffentlicht.

## ✨ Features

- 🎨 Moderne, animierte Benutzeroberfläche mit p5.js
- 🎯 Smooth Drop-Animationen für fallende Spielsteine
- ✨ Hover-Effekte und visuelle Rückmeldungen
- 🏆 Gewinn-Animation mit pulsierenden Effekten
- 🔄 Einfacher Neustart-Button
- 📱 Responsive Design

## 🎮 Spielanleitung

1. Spieler 1 (rot) und Spieler 2 (gelb) sind abwechselnd am Zug
2. Klicke auf eine Spalte, um deinen Spielstein fallen zu lassen
3. Ziel: Verbinde 4 Steine deiner Farbe in einer Reihe (horizontal, vertikal oder diagonal)
4. Der erste Spieler, der 4 Steine in einer Reihe hat, gewinnt!

## 🛠️ Technologie

- **p5.js** - Für die visuelle Darstellung und Animationen
- **Pure JavaScript** - Keine Build-Tools erforderlich
- **GitHub Actions** - Automatisches Deployment zu GitHub Pages

## 📦 Lokale Entwicklung

Um das Spiel lokal zu testen:

1. Klone das Repository
2. Öffne `index.html` in einem modernen Browser
3. Alternativ: Nutze einen lokalen Webserver (z.B. `python -m http.server`)
